# 請幫我建立一個 客戶預約服務中心 網站 請直接開始建立可操作的網站 MVP 一 網站定位 這是一個提供客戶線上預約服務的網站 主要流程 首頁 選擇服務 選擇日期 選擇時間 填寫預約資料...

請幫我建立一個「客戶預約服務中心」網站，請直接開始建立可操作的網站 MVP。

## 一、網站定位

這是一個提供客戶線上預約服務的網站。

主要流程：

首頁
→ 選擇服務
→ 選擇日期
→ 選擇時間
→ 填寫預約資料
→ 確認資料
→ 完成預約

另外需要一個管理員後台：

管理員登入
→ 查看預約
→ 查看客戶資料
→ 管理預約狀態
→ 管理可預約時段

網站主要使用繁體中文，請使用台灣常用的繁體中文，不要使用簡體中文。

# 十七、非常重要的預約邏輯

請確保：

1. 同一時間只能有一筆有效預約。
2. 已經被預約的時段不能再次預約。
3. 使用者完成預約時，再次檢查該時段是否仍然可用。
4. 避免兩個使用者同時預約造成 double booking。
5. 預約成功後自動產生唯一預約編號。
6. 取消預約後，該時段可以重新開放預約。
7. 過去日期不能預約。
8. 已取消的預約不應佔用可預約時段。
9. 所有日期與時間要按照台灣時區 Asia/Taipei 處理。
10. 所有表單都要進行基本資料驗證。

# 十八、錯誤處理

如果預約失敗：

顯示：

「預約未完成，請稍後再試。」

如果時段剛好被其他人預約：

「很抱歉，此時段剛剛已被其他客戶預約，請重新選擇時間。」

如果表單缺少資料：

「請確認必填欄位是否已完成。」

錯誤訊息請使用繁體中文。

# 二十、資料安全

這個網站可能會處理客戶個人資料，因此請採取基本安全設計。

不要收集非必要的高度敏感資訊，例如：

* 身分證字號
* 銀行帳號
* 網銀密碼
* 信用卡資料
* 金融帳戶密碼

資料庫必須設定適當的存取權限。

一般客戶只能查看自己的預約。

一般客戶不能查看其他客戶資料。

只有管理員可以查看完整預約管理資料。

前端不能直接暴露管理員權限。

# 二十二、開發方式

請不要一次建立過度複雜的功能。

優先完成：

1. 客戶預約
2. 選擇日期
3. 選擇時間
4. 填寫資料
5. 預約確認
6. 預約成功
7. 查詢預約
8. 管理員登入
9. 管理員查看預約
10. 管理員修改預約狀態
11. 時段管理
12. 基本資料安全

先完成一個可以實際操作的 MVP。

請確保所有按鈕與頁面都有實際功能，不要只做靜態 UI。

如果需要在技術實作上做決定，請優先選擇穩定、容易維護、適合 MVP 的方案。

完成後請檢查：

* 預約流程是否可以完整跑完
* 時段是否會重複預約
* 預約編號是否唯一
* 管理員是否可以查看預約
* 手機版是否正常
* 表單驗證是否正常
* 錯誤訊息是否完整
* 中文文字是否全部為繁體中文

請直接開始建立第一版網站。
